# Folder Audio — Nada Latar Bernuansa Arab

Letakkan file musik instrumental bernuasa Arab (oud, qanun, percussion lembut,
atau nada latar Islami) di folder ini dengan nama persis seperti berikut:

| Nama file            | Judul lagu (tampil di player) |
|----------------------|-------------------------------|
| `tahayyaltu.mp3`     | طَيِّبَة (Thayyibah)          |
| `assuq.mp3`          | السُّوق (As-Sūq)              |
| `alqamar.mp3`        | الْقَمَر (Al-Qamar)            |
| `alhadyah.mp3`       | الْهَدْيَة (Al-Hadyah)         |

## Catatan
- Format yang didukung browser: **.mp3** (disarankan), .m4a, atau .ogg
- Selama file di atas belum ada, pemutar **otomatis** memakai lagu instrumental
  demo (SoundHelix) agar tetap berbunyi.
- Menambah / mengganti lagu: edit array `PLAYLIST` di `js/music-player.js`.

## Sumber musik gratis (boleh dipakai)
Cari "arabic oud instrumental royalty free" atau "nasheed background music"
di pustaka bebas royalti seperti Pixabay Music, Free Music Archive, atau
Incompetech — pastikan lisensinya mengizinkan pemakaian di web Anda.
